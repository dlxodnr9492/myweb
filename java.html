JAVA 복습 페이지 입니다

그동안 배웠던 JAVA에 대해 복습할 수 있는 3문제를 냈어요. 최선을 다해 맞혀주세요.

문제 1. 인터페이스와 오버라이딩 규칙
클래스가 부모 클래스를 상속받을 때는 extends를 씁니다. 그렇다면 만들어진 인터페이스(예: InfoManger)를 클래스에 장착할 때 쓰는 키워드는 무엇이며,
인터페이스 안에 선언된 메서드를 클래스에서 구현(오버라이딩)할 때 에러가 나지 않으려면 메서드 앞에 반드시 붙여야 하는 키워드(접근 제어자)는 무엇일까요?


문제 2. Object의 한계와 마법의 이름표
부모 리모컨으로 자식 객체를 다루다가, 자식 고유의 기능(예: basic_salary)을 쓰기 위해 (Permanent_employee)e 처럼
강제로 타입을 내리는 것을 '다운캐스팅(Downcasting)'이라고 합니다.
그런데 모든 객체를 담을 수 있는 최상위 부모인 Object 상자를 쓰면 꺼낼 때마다 매번 이 다운캐스팅을 해야 해서 너무 귀찮고 위험합니다.
이를 해결하기 위해 아예 클래스나 인터페이스 이름 옆에 T 같은 이름표를 붙여서 "이 상자는 얘 전용이야!"라고 찜해버리는 문법의 이름은 무엇일까요?


문제 3. 자바 컬렉션 3대장의 용도
데이터를 저장할 때 0번, 1번 같은 '번호표(인덱스)'를 매겨서 관리하며 크기가 무한히 늘어나는 것은 ArrayList (List 구조)입니다.
그렇다면 번호표 대신 학번이나 이름 같은 '이름표(Key)'를 부여해서 데이터를 저장하며,
Key는 절대 중복될 수 없고 파이썬의 딕셔너리(Dictionary)와 완벽하게 똑같이 동작하는 이 자료구조의 이름은 무엇일까요?
